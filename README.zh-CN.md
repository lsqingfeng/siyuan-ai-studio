# AI 创作工坊 (SiYuan AI Studio)

> 思源笔记原生 AI 创作副驾驶 · 在侧边栏与 AI 边聊边写，流式极速响应，支持默认感知当前打开文档、全库知识检索 (RAG)、一键回填覆盖原文档与一键创建新笔记！  
> **100% 纯前端/Node 实现，零 Python 依赖，零外部端口，即装即用。**

---

## 🌟 核心特性

1. **默认无感感知当前打开的文档**：
   - 侧边栏常驻实时文档感知指示条，自动读取正在编辑的文章全文；
   - 随口说“润色”、“总结”、“扩写”，AI 自动基于当前真实原文处理，告别复制粘贴。

2. **全自动意图识别与闭环执行（去按钮化）**：
   - **知识库问答与检索**：如 *“搜一下测试环境账号密码”*，自动触发思源全库检索并卡片化精准定位到具体章节；
   - **自动创建新笔记**：如 *“写一篇 Docker 总结存到 /技术文档 目录”*，自动提取纯净自然语义路径落盘；
   - **成稿一键写回**：润色成稿下方提供【📝 一键回填至文档】与【⚡ 原地替换段落】，实现完整操作闭环。

3. **极速流式响应与多模型支持**：
   - 深度支持 DeepSeek-V4 Pro / Flash、DeepSeek-V3 / R1、GPT-4o、Claude 3.5、Kimi 等主流模型；
   - 兼容自定义 OpenAI 协议与本地 Ollama 模型，支持 SSE 打字机流式输出。

4. **快捷呼出与沉浸创作**：
   - **快捷键**：按 **`⌥A`**（Option + A）秒级呼出独立对话窗口；
   - **右侧侧边栏**：点击思源右下角 Dock 栏中的 ✨ 图标，可将 AI 创作工坊常驻在思源右侧，边读笔记边写方案！

---

## 🚀 安装与使用

### 通过思源集市安装（推荐）
在思源笔记中打开 **设置 -> 集市 -> 插件**，搜索 **“AI 创作工坊”** 或 **“AI Studio”**，点击安装即可。

### 手动安装
将本项目解压至思源插件目录：
`思源笔记数据目录/data/plugins/siyuan-ai-studio`
重启思源笔记后，在设置中启用插件。
